# ABM教学实验平台

## 项目简介

ABM教学实验平台是一个基于Streamlit开发的交互式学习系统,旨在帮助学习者从原理到应用全面掌握基于智能体建模(Agent-Based Modeling)方法。平台集成了理论讲解、交互实验和案例分析,特别聚焦于金融与农业金融保险领域的ABM应用。

## 核心功能

### 📚 系统化学习路径

- **第一章: ABM基本原理与方法论** - 理解ABM的核心概念和理论基础
- **第二章: ABM建模标准流程** - 掌握从设计到实现的完整建模流程
- **第三章: 经典案例学习** - 通过Schelling隔离、Sugarscape等经典模型深入学习
- **第四章: 金融ABM应用** - 探索银行系统风险传染、股票市场等金融领域应用
- **第五章: 农业金融保险ABM** - 聚焦农业保险、农户决策等专业领域

### 🎮 交互式实验功能

- **实时参数调整** - 通过侧边栏动态调整模型参数
- **可视化展示** - 使用Plotly和NetworkX实现动态网络和数据可视化
- **进度跟踪** - 自动保存学习进度,支持断点续学
- **字体缩放** - 支持小/中等/大/特大四级字体调整

### 🔬 内置经典模型

- Schelling隔离模型
- Sugarscape资源竞争模型
- Conway生命游戏
- 银行风险传染模型
- 农业保险决策模型

## 技术栈

- **前端框架**: Streamlit
- **ABM核心**: Mesa 3.x
- **数据分析**: Pandas, NumPy
- **可视化**: Plotly, Matplotlib, NetworkX
- **网络分析**: NetworkX

## 安装指南

### 环境要求

- Python 3.8+
- pip包管理器

### 安装依赖

```bash
# 进入项目目录
cd 代码/实验平台设计

# 安装依赖包
pip install -r requirements.txt
```

### 启动平台

```bash
streamlit run abm_teaching_platform.py
```

启动后在浏览器中访问 `http://localhost:8501`

## 使用指南

### 学习模式

1. **左侧导航栏**: 选择学习章节和小节
2. **中间内容区**: 阅读理论讲解并参与交互实验
3. **右侧工具栏**: 调整模型参数和可视化设置
4. **进度记录**: 系统自动保存学习进度至 `learning_progress.json`

### 实验操作

- 点击"运行实验"按钮启动模拟
- 使用滑块和下拉框调整参数
- 观察可视化结果的动态变化
- 导出实验数据用于深入分析

✅ **零代码交互** - 通过图形界面调整参数,无需编程基础  
✅ **理论实践结合** - 每个章节配备对应的交互实验  
✅ **专业领域聚焦** - 深度覆盖金融与农业金融保险场景  
✅ **开源可扩展** - 基于Mesa框架,可自定义添加新模型
